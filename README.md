# KARAOKE TV — Домашняя караоке-система для Android TV

Полноценное мультимедийное приложение для Android TV-приставок (Google TV / Android TV 9.0+), объединяющее бесплатные караоке-минусовки с текстом из **YouTube**, **VK Видео** и **RUTUBE** в единый умный каталог без дубликатов.

---

## 1. Концепция и аппаратная конфигурация

**Главный принцип:** Пользователь включает телевизор, находит песню, добавляет её в очередь и поёт. Никаких демонстрационных макетов — полнофункциональная караоке-система.

### Целевое оборудование
- **ТВ-приставка:** Android TV / Google TV (Android 9.0 / API 28+).
- **Экран:** Телевизор через HDMI (поддержка 1080p Full HD и 4K).
- **Акустическая система:** Караоке-колонка **Soundcore Rave 3S**.
- **Микрофоны:** Два штатных беспроводных микрофона Soundcore (подключаются напрямую к колонке по радиоканалу, смешивание звука выполняет сама колонка).
- **Аудиовыход:** Системный Bluetooth A2DP с ТВ-приставки на Soundcore Rave 3S.
- **Управление:** Любой Android- или iOS-смартфон в домашней Wi-Fi сети через QR-код (без установки приложений).

## 2. Архитектура и стек технологий

Проект построен по принципам **Clean Architecture** и **MVVM**:

- **Язык:** Kotlin 2.0+ (100% Kotlin).
- **Пользовательский интерфейс:** Jetpack Compose for TV (`androidx.tv.material3`, `androidx.tv.foundation`).
- **Локальная база данных:** Room 2.6.1 (10 сущностей: `Song`, `KaraokeVersion`, `Rating`, `QueueItem`, `Participant`, `Favorite`, `PlaybackHistory`, `SearchHistory`, `PlaybackFailure`, `SourcePreference`).
- **Сетевой слой:** Retrofit 2.11 + OkHttp 4.12 + Gson (асинхронные корутины, параллельный опрос источников).
- **Медиаплееры:**
  - YouTube: Официальный YouTube IFrame API через оптимизированный WebView (`android-youtube-player`).
  - RUTUBE: Официальный HTML5-фрейм `rutube.ru/play/embed/{id}` с двусторонним мостом postMessage JS.
  - VK Видео: Официальный плеер `video_ext.php` с обработкой postMessage.
  - Локальный / Аудио: Media3 ExoPlayer для тестовых сигналов и калибровки синхронизации.
- **Локальный веб-сервер:** Встроенный HTTP & WebSocket сервер на ТВ-приставке (порт 8888), транслирующий очередь в реальном времени на экраны смартфонов гостей.
- **Генерация QR-кода:** ZXing Core.
- **Асинхронность:** Kotlin Coroutines (`Dispatchers.IO`, `SupervisorJob`) и StateFlow.

## 3. Источники караоке: возможности и ограничения

| Параметр | YouTube | VK Видео | RUTUBE |
| :--- | :--- | :--- | :--- |
| **API поиска** | YouTube Data API v3 (`/search`) | VK API (`video.search`) | Публичный REST API (`/api/search/video/`) |
| **API-ключ** | Требуется ключ Google Cloud | Требуется токен VK | **Не требуется** (работает из коробки) |
| **Встроенный плеер** | YouTube IFrame Player (WebView) | VK HTML5 Embed (`video_ext.php`) | RUTUBE HTML5 Embed (`/play/embed/`) |
| **Событие окончания** | `PlayerState.ENDED` | postMessage (`video:ended`) | postMessage (`player:changeState` -> `ended`) |
| **Внешний переход** | Intent в приложение YouTube | Intent в приложение VK Видео | Intent в приложение RUTUBE |
| **Качество видео** | До 1080p / 4K | До 1080p | До 1080p |

## 4. Ключевые возможности системы

### 4.1. Умный каталог без повторов (Smart Deduplication)
Если песня найдена в нескольких сервисах, она объединяется в единую карточку (например, «Кино — Группа крови»).
- Алгоритм нормализации отсекает служебный шум: `караоке`, `karaoke`, `минусовка`, `lyrics`, `с текстом`, `1080p`, `HD`.
- Нечёткое сравнение по расстоянию Левенштейна (порог схожести 80%+).
- Защита от ошибочного объединения: ремиксы, акустические версии и версии с изменением тональности сохраняются как отдельные композиции.

### 4.2. Автоматический выбор лучшей минусовки (Smart Ranking)
При нажатии «Петь» система оценивает:
1. Доступность источника и отсутствие ограничений встраивания.
2. Вероятность того, что это действительно караоке с текстом (эвристика `KaraokeScorer`).
3. Локальные оценки пользователей (1–5 звёзд с доверительным коэффициентом).
4. Качество видео (4K > 1080p > 720p).
5. Приоритет пользователя (настраивается в Настройках).

### 4.3. Оценка качества минусовок
После окончания песни выводится ненавязчивое окно оценки:
- От 1 до 5 звёзд.
- Причины: *«Отличная минусовка»*, *«Хорошо читаемый текст»*, *«Хороший звук»*, *«Текст не совпадает с музыкой»*, *«Присутствует вокал»*, *«Плохой звук»*, *«Отсутствует текст»*, *«Это не караоке»*.
- Оценки сохраняются локально в Room DB и учитываются при последующем ранжировании.

### 4.4. Управление со смартфонов без установки приложений
1. Нажмите в меню кнопку **«Подключить телефон»**.
2. На экране ТВ отобразится QR-код со ссылкой `http://<IP_ПРИСТАВКИ>:8888/?token=<TOKEN>`.
3. Гости сканируют код и в браузере телефона получают:
   - Живую очередь выступлений (синхронизация по WebSocket без задержек).
   - Полнотекстовый поиск по всем сервисам.
   - Добавление треков в очередь с указанием своего имени (*«Валера»*, *«Настя»*).
   - Оценку качества спетой минусовки.
   - **Режим ведущего:** защищён 4-значным PIN-кодом с экрана ТВ. Позволяет ставить на паузу, перематывать, пропускать песни и менять порядок в очереди.

### 4.5. Режим вечеринки (Party Mode)
- Красочный полноэкранный интерфейс с заставкой для следующего исполнителя (*«СЛЕДУЮЩИЙ НА СЦЕНЕ: Валера — Кино, Группа крови»*).
- История выступлений за текущий вечер.
- Переключатель анимаций для слабых ТВ-приставок (1-2 ГБ ОЗУ).

### 4.6. Интеграция с Soundcore Rave 3S
- Автоматическое определение Bluetooth-аудиовыхода (`AudioDeviceInfo.TYPE_BLUETOOTH_A2DP`).
- Калибровка задержки аудио/видео (A/V Sync Offset от -500 мс до +500 мс).
- Инструкция по подключению колонки и беспроводных микрофонов.

## 5. Настройка API-ключей

### RUTUBE
Не требует настройки! Работает сразу после первого запуска.

### YouTube Data API v3 (опционально, для поиска на YouTube)
1. Откройте [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте проект и перейдите в раздел **APIs & Services** → **Library**.
3. Найдите **YouTube Data API v3** и нажмите **Enable**.
4. В разделе **Credentials** нажмите **Create Credentials** → **API Key**.
5. Скопируйте ключ и введите его в **Настройках Karaoke TV** (удобнее всего вставить через веб-пульт со смартфона).

### VK Видео (опционально, для поиска ВКонтакте)
1. Откройте [VK Developers](https://vk.com/dev).
2. Создайте Standalone-приложение.
3. В настройках приложения скопируйте **Сервисный ключ доступа** (Service Token).
4. Вставьте его в поле **VK Access Token** в Настройках приложения.

## 6. Установка на Android TV-приставку

### Вариант 1. Установка через флешку (USB)
1. Соберите APK-файл (или возьмите готовый debug APK):
   `./gradlew assembleDebug` (файл в `app/build/outputs/apk/debug/app-debug.apk`).
2. Скопируйте `app-debug.apk` на USB-флешку.
3. Подключите флешку к ТВ-приставке.
4. Откройте любой файловый менеджер на ТВ (например, X-plore или File Commander).
5. Разрешите установку из неизвестных источников и запустите файл.

### Вариант 2. Установка через приложение Downloader
1. Установите приложение **Downloader by AFTVnews** из Google Play на Android TV.
2. Введите прямую ссылку на APK или локальный адрес в сети.
3. Нажмите **Install**.

## 7. Результаты тестирования

Проект содержит модульные тесты в папке `app/src/test/java/com/karaoke/tv/domain/`:
1. `DeduplicationEngineTest`:
   - Нормализация артистов и названий с удалением шума (`karaoke`, `HD`, `lyrics`).
   - Разделение оригиналов и ремиксов (ремиксы не сливаются с оригиналами).
   - Разделение акустических версий.
   - Разделение разных треков одного исполнителя.
   - Объединение версий из разных сервисов в единый объект `Song`.
2. `RankKaraokeVersionsUseCaseTest`:
   - Приоритет проверенных минусовок с высокими оценками.
   - Пенализация недоступных и заблокированных роликов.
   - Учёт пользовательского приоритета источников.
   - Отсев клипов и не-караоке контента.
3. `QueueLogicTest`:
   - Корректная работа FIFO-очереди.
   - Перемещение элементов выше/ниже пультом и смартфоном.
   - Пропуск песни и передача микрофона следующему участнику.
